# 42 BioTech: инвентарь

Лабораторный инвентарь электроники и компонентов. Данные хранятся в CSV: их удобно читать прямо в GitHub, а в истории коммитов видны построчные изменения.

| Файл | Содержимое | Позиций |
|---|---|---|
| `electronics.csv` | Готовые устройства: питание, полётные и видеосистемы, радио, камеры, антенны, моторы, платы-доноры и детали с них | 29 |
| `components.csv` | Детали, модули и платы: транзисторы, микросхемы, пассивные, платы разработки, датчики | 86 |
| `tools.csv` | Измерительные приборы и инструменты (заполняется) | 7 |

## Колонки

- **№**: сквозной номер внутри файла.
- **Источник**: откуда позиция пришла (исходный лист и номер или дата добавления).
- **Категория / группа**: крупная группа.
- **Подгруппа** (только `components.csv`): Транзисторы, Микросхемы, Пассивные, Датчики, Светодиоды, Антенны/ВЧ, Прочее. У модулей и плат пустая.
- **Название / маркировка**, **Тип / назначение**, **Корпус**, **Ключевые параметры**.
- **Состояние**: «Не проверено» по умолчанию.
- **Кол-во**, **Где лежит**, **Примечания**.

## Правила

- Новые позиции добавляются в конец файла, нумерация продолжается.
- Неподтверждённые данные помечаются в тексте («вероятно», «предположительно»).
- Перед первым включением неопознанных плат: проверить полярность и КЗ, питать через ограничение тока.
